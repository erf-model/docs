static

The one list of the variables. The reader asks the file for every name in it, and takes the layout of a name from its kind.

The bounds leave out only values that cannot be the named quantity (a negative temperature, a fraction above one). A field that a hand-built file declares and leaves at zero passes; whether zero is usable is for the code that takes the field. The upper bounds of LAI, TMN, ZNT, SNOW, SNOWH, TSLB, ZS and DZS are not physical limits: they are set far above any value of the quantity so that a NetCDF fill value (9.97e36), which is finite, is left out.

The valid cells of the level inside file_box take the file's values. A soil field gets one component per layer, in the file's order. The values are counted against the catalog range here; the report, the decision and the ghost cells are left to finish_level().

Close the read of a level, after the last file. Collective: every rank calls it.

Reduces the counts and ranges of fill() over the ranks (two reductions for the level, whatever the number of fields), then for every field read: reports it and fills its ghost cells; or, when a valid cell was not covered by a file, a value lies outside the catalog range, a value is not finite, or two files disagree on the number of layers, reports that with the counts and drops the field. Then drops TSLB, SMOIS, ZS and DZS together when they disagree on the number of soil layers.
