Add the face heat flux to the temperature equation: every face deposits H A / (c_p V Pi) into the rho-theta source of its fluid cell (Pi the Exner function, so the flux heats the cell by H A / (c_p V) in temperature). Called after the sources are rebuilt at every slow stage; adds, never overwrites, and uses atomic adds because a corner cell receives several faces.

Face flux into the temperature equation. The rho-theta tendency of the fluid cell is H A / (c_p V Pi); with several faces on one cell the adds are atomic.

void IBFaceSet::add_outside_occluders ( const std::vector< const IBFaceSet * > &  below)

Add the buildings this refined level does not hold to the ray map of its ray cast, from the column maps of the levels below.

build() takes the map from the level's own cells, so on a refined level that covers part of the domain the rays of the shortwave and the view fractions would pass through every building outside it. The ray map is rebuilt with the halo for the tallest column of every level, and each column of the patch that this level's grids do not cover takes the top of the finest level below that covers it (ERF::ibseb_check_refined_levels() has made sure a building is wholly inside or wholly outside each level), on the ratio x ratio columns of this level beneath the coarse one, at the same height. Only the ray cast reads the result: the building ids, the face heights of the wall function and the reports keep the level's own buildings. Call after build() of every level involved and before compute_view_fractions().

Parameters
belowFace sets of levels 0 to this level's minus one, in that order.

Rebuild the ray map with the buildings of the levels below (see the header and build_ray_map()).

void IBFaceSet::build ( const amrex::MultiFab &  blanking,
const amrex::Geometry &  geom 
)

Detect this rank's faces from the cell-centred blanking and allocate every per-face array.

Runs on the host once at initialisation: the blanking is copied fab by fab (a pinned copy on GPU builds), the valid cells are scanned, and the arrays are uploaded to the device at the end. Must be called after the blanking has been built and its ghost cells filled, since the solid neighbour of a fluid cell on a box edge lives in a ghost cell. Stops when a solid cell outside the level's grids neighbours a cell of the level, fluid or solid: a building across the edge of a refined level.

Parameters
blankingCell-centred blanking of the level (needs at least one ghost cell, filled).
geomGeometry of the level: cell sizes for the face areas, domain and periodicity for the neighbour tests.

Detect the faces owned by this rank and allocate the per-face arrays.

The scan visits every valid cell of every local fab in MFIter order, once. A fluid cell (blanking < 0.5) contributes one face for each of its six neighbours that is solid (blanking >= 0.5); the neighbour may sit in a ghost cell, which is why the blanking must have its ghost cells filled. Neighbours outside the domain in a non-periodic direction are skipped, so a building against a non-periodic boundary has no face there. Solid cells contribute no face, only the column map (the highest solid cell of each column of the level's own boxes) that the building ids and the ray cast read. A solid neighbour outside the level's grids, of a fluid or a solid cell, means a building crosses the edge of a refined level; the scan counts them and stops the run once all ranks have reported.

Faces are appended in scan order, which makes them contiguous per fab; m_fab_start records where each fab's faces begin. The per-direction, per-building and total counts are reduced over all ranks here, once, so report() does not have to reduce static numbers every time. Nothing of the size of the domain is gathered: the column map is exchanged through its ghost cells, the building labels through theirs (see the header), and the one gather is of the distinct labels, one per building.

private

Build the ray map (m_ray_patch) from m_col_valid and the levels below. The halo is sized for the shallowest ray the map must follow to its end: the shallowest ray of the hemisphere sampling (ibseb::hemisphere_min_sz()) and a sun erf.ibseb.sun_min_elev_deg above the horizon, over the tallest column of this level and the levels below, height / tan(elevation) cells in x and in y (ibseb::ray_halo_cells()). A rising ray stops above the tallest column and a falling one at the ground, so within that reach the walk is exact, and beyond it only a sun lower than the floor is concerned, whose direct beam the clear-sky attenuation has all but removed; a building farther than the halo from a face then casts no shadow on it (the far field is open ground). The patch is this rank's boxes grown by the halo, clipped to the domain where it is not periodic and, where it is, reduced to one domain width when the grown box is at least that wide, in which case the walk wraps round and is exact for any reach.

◆ write_state()

void IBFaceSet::write_state ( const std::string &  file) const

Write the face state (skin temperature, sensible flux and slab temperatures) to file for the checkpoint: one record per face of the level, in one global order, written by the I/O rank.

The file holds one text line, IBSEBFaces 1 <nface> <n_layers> <nx> <ny> <nz> (the format version, the level's face count, the slab layers per face and the domain size in cells), then in binary a marker word (0x0102030405060708 as a 64-bit integer, so a file from a machine with another byte order is refused), the nface keys as 64-bit integers in ascending order, then the nface x (2 + n_layers) values as doubles: a face's skin temperature, its sensible flux (read as the previous step's by the convective velocity scale) and its slab layers from the skin inward. The key of a face is ((i ny + j) nz + k) 6 + 2 dir + (side > 0) with (i, j, k) counted from the domain's low corner, so it names the face whatever the rank count. The values are doubles whatever amrex::Real is, so a single-precision run reads a double-precision checkpoint and the other way round. The file costs 8 (3 + n_layers) bytes per face beyond its header line and marker, which is the data itself: the cell field it replaces covered the face-owning cells with whole boxes and was about eleven times larger on the FaceStorage skyscraper (erf-model/ERF#4019).

Every rank copies its faces to the host and sorts them by key; the I/O rank gathers the records, orders them and writes the file. Collective: every rank must call it.

One record per face, gathered on the I/O rank and written in key order: the header line, the sorted keys, then the values record by record. Every rank sorts its own faces first so the gathered runs are ordered; the I/O rank then merges them by sorting an index over all the records.
