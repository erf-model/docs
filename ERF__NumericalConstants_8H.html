Detailed Description

Dimensionless numeric literals and pure mathematical constants.

Nothing in this file is physics. These are spelling aids that let the code write myhalf instead of amrex::Real(0.5) and so stay precision-agnostic between double and single (AMREX_USE_FLOAT) builds, plus the mathematical constant pi and the two combinations of it that recur often enough to be worth naming.

Kept separate from ERF_Constants.H so that a file needing only numeric literals does not have to pull in the thermodynamic constants, and so that ERF_Constants.H reads as a list of physical constants. ERF_Constants.H includes this header, so every existing consumer keeps compiling unchanged.
