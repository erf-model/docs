The checks on the level the surface grid refines, each naming the inputs to change.

  1. The level exists (0 to the finest level).
  2. Above level 0, the level keeps its boxes (erf.regrid_int <= 0): the grid is built once.
  3. Every box spans the level's full height: the grid pairs one surface slab with each box, and reads whole columns.
  4. The boxes cover one rectangle: the grid treats its edges as domain edges.
  5. The level's domain starts at index 0 (the map i / C + atm_lo assumes it).
