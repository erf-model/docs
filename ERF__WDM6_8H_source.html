123  // WDM6 module parameter constants (from WRF module_mp_wdm6.F)
124  //
125  // LITERAL PRECISION CONTRACT
126  // --------------------------
127  // Every constant below is initialised through wdm6_literal() rather than
128  // written directly, because the two implementations do not agree on what
129  // these literals mean.
130  //
131  // In ERF_module_mp_wdm6.F90 the parameters are declared
132  // real(kind=kind_phys), parameter :: dimax = 500.e-6
133  // with NO kind suffix on the literal. Fortran therefore evaluates the
134  // literal as a default (single-precision) real and only then widens it to
135  // kind_phys, so the stored value carries float32 rounding permanently.
136  // All 22 parameters in that module are written this way; none is suffixed.
137  // dimax for instance is +5.00000023748725652695E-04 in the Fortran, which
138  // is bit-for-bit float32(5e-4) widened, against a true double
139  // +5.00000000000000010408E-04 here.
140  //
141  // That single 2.37e-11 difference is the confirmed root cause of the first
142  // materially failing group in the tag-frontier retreat: it clamps
143  // diameter, which drives pidep in G13e, which amplifies into psaut in G13f
144  // and on into the Milestone A and B plotfile failures.
145  //
146  // ERF_WDM6_F32_LITERALS selects which side to match:
147  // defined reproduce the Fortran-as-compiled-today values bit-for-bit
148  // undefined use true doubles, which is correct when the Fortran side is
149  // built with -fdefault-real-8 so its literals are doubles too
150  //
151  // Four constants (actk, bvtr, bvts, satmax) previously carried a hand-added
152  // 'f' suffix. That was an undocumented partial fix covering 4 of 22 and it
153  // would have silently fought a -fdefault-real-8 build. Those suffixes are
154  // absorbed here so the choice is made in exactly one place.
155  //
156  // Note r0, peaut and alpha_wdm6 have no matching Fortran parameter of the
157  // same name and value, so their correspondence is unverified; they are
158  // routed through the same helper for uniformity, not because a match is
159  // established.
160  //
161  // wdm6_literal is defined at namespace scope above rather than as a member:
162  // a constexpr member function cannot be called in a constant expression
163  // inside its own class body, because the class is incomplete until the
164  // closing brace.
