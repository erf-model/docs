16 /**
17  * Morrison, WSM6 and WDM6 sediment each column inside one per-column kernel over the
18  * k range of the box they are handed: the box top is treated as the top of the column
19  * (no inflow) and the box bottom as its ground (outflow booked as surface precipitation).
20  * That is only right when no column is split between boxes.
21  *
22  * This class records, for one level's grids, whether any column is split between boxes
23  * stacked in z, and if so builds a "column layout": a BoxArray covering exactly the same
24  * cells in which every contiguous vertical run of covered cells lies inside one box. A
25  * scheme then copies its fields onto that layout, runs its unchanged column kernels, and
26  * copies the result back. The kernels only read and write their own column, so this gives
27  * the same arithmetic as a run whose grids were never split in z.
28  *
29  * A run that does not reach the domain bottom (e.g. a refined patch aloft) has no ground,
30  * so the schemes accumulate surface precipitation only where klo is the domain bottom.
31  */

61  if (saved[n]) { saved[n]->ParallelCopy(*vars[n], 0, 0, vars[n]->nComp()); }
