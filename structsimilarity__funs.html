Detailed Description

Structure of similarity functions for Moeng formulation.

The unstable side is Businger-Dyer. The stable side is Businger-Dyer (the default, phi = 1 + beta zeta, psi = -beta zeta) or, after set_stable_functions, the QNSE form phi = (1 + a zeta)/(1 + b zeta), psi = -((a - b)/b) ln(1 + b zeta) of Sukoriansky, Galperin and Perov (2005), with its own coefficients for momentum and heat (most.stable_functions, read by read_most_similarity_funs). The Jimenez (2012) pair (calc_psi_m2, calc_psi_h2) is not affected by the choice.

AMREX_GPU_HOST_DEVICE AMREX_FORCE_INLINE amrex::Real similarity_funs::calc_phi_m ( amrex::Real  zeta) const
inline

Compute the momentum gradient function (Businger-Dyer, or QNSE on the stable side).

This is the exact companion of calc_psi_m: the two are tied by psi_m(zeta) = int_0^zeta (1 - phi_m(x))/x dx, so differentiating the MOST wind profile u(z) = (u_star/kappa)[ln(z/z0) - psi_m(z/L)] gives du/dz = u_* phi_m(zeta) / (kappa z).

NOTE: the surface_temp* flux calculators use the Jimenez psi pair (calc_psi_m2/calc_psi_h2) rather than this one; their companions are not implemented yet, so a prescribed-surface-temperature run gets the Businger-Dyer gradient here.

AMREX_GPU_HOST_DEVICE AMREX_FORCE_INLINE amrex::Real similarity_funs::calc_zeta_fold ( amrex::Real  C) const
inline

Stable z/L at which the prescribed-flux problem folds.

With L fixed by u* and the flux, the wind a given u* supports is u* max(C - psi_m, b) / kappa, with b = most_bracket_floor(C). Below the smallest such wind the prescribed stable flux has no solution with z/L below most_zeta_lim (Basu et al., BLM 2008; with QNSE the supported wind rises again past its first minimum to a local maximum at the second zero of f below, at z/L of order 1e3 to 1e4, and only then tends to zero with u*; the kernels never reach that range). The physical (large u*) branch has z/L below this value, so bounding z/L by it leaves every point that has a solution unchanged. The result is positive for every C.

Businger-Dyer (psi_m = -beta_m z/L): for C > 0 the minimum is at z/L = C / (2 beta_m); for small or negative C (z0 near or above zref) the floor binds first and the minimum is at the kink z/L = (b - C) / beta_m.

QNSE (psi_m = -c ln(1 + b_m z/L), c = (a_m - b_m)/b_m): with u* proportional to (z/L)^(-1/3), the supported wind falls with z/L while f(z/L) = C + c ln(1 + b_m z/L) - 3 c b_m (z/L) / (1 + b_m z/L) is positive, and f falls from C at z/L = 0 to its minimum at z/L = 2 / b_m and rises without bound after it. The fold is the first zero of f beyond the kink where the floor stops binding (C - psi_m = b), found by Newton's method on the bracket [kink, 2 / b_m] where f is convex and decreasing (f' = c b_m (b_m z/L - 2) / (1 + b_m z/L)^2 < 0, f'' > 0 for b_m z/L < 5): after the first step the iterates approach the root from the left, a step that would leave the bracket is replaced by its midpoint, and the iteration stops at a relative change of 1e-10 (a handful of steps against the 60 passes of a bisection to the same precision; the roughness kernels call this once per u* iteration). It is the kink itself when f is already negative there, and most_zeta_lim when f has no zero (C > c (2 - ln 3), 10.4 with the default coefficients): the wind then falls monotonically with z/L up to the bound, where the kernels hold z/L and reduce the flux as at a fold. Every return value is at most most_zeta_lim.
