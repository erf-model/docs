Detailed Description

Bounded mapped advection for the authoritative SBM spectrum.

The state manager remains the owner of prognostic state. This object owns per-level stage scratch, the static mapped measure, the compact projected qc/qr completed-step face ledger, and (in reference mode) an optional all-component completed spectral face ledger. Production AMR instances add accepted chunk-local stage rates directly to their pending interface YA register and do not retain that full spectral ledger. Operational AMR execution remains disabled by the ERF runtime guard until lifecycle gates are qualified.
