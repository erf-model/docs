Detailed Description

The flood engines compiled into this executable.

ERF lists no engine itself. Each engine registers itself from its own .cpp with 

ERF_REGISTER_FLOOD_ENGINE(MyEngine, "myengine")

at namespace scope, and erf.flood.engine then selects it by that name. The engine's directory (FLOOD_HOME in GNU make, ERF_FLOOD_ENGINE_DIRS in CMake) adds that .cpp to the build, so adding an engine changes no file of ERF.

The registration runs during static initialization, so the .cpp that holds it must be linked as an object file: inside a static archive (.a) that nothing else references, the linker drops it and the engine is missing. ERF's CMake build compiles engines into its OBJECT library, and GNU make links every object, so both keep it; an engine that ships a prebuilt library keeps its registering .cpp as source.

The registry follows the fire-engine registry (ERF_FireEngineRegistry.H) and is independent of it: a build may hold fire engines, flood engines, both or neither.
