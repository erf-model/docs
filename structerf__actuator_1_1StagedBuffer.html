Detailed Description

template<class T>
struct erf_actuator::StagedBuffer< T >

An array filled on the host and read by the kernels: the host side is a std::vector (clear() keeps its capacity), copied through pinned memory to the device with one asynchronous copy. The pinned and device sides only grow. A call that uploads must synchronise the stream before it returns, so that the next call may refill the host side.
