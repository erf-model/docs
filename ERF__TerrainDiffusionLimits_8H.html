Explicit fraction of the vertical diffusion for the diffusive time-step check: 0 if every stage of the partly implicit Runge-Kutta scheme stays bounded for the vertical diffusion, 1 otherwise (including every pattern for which that has not been shown).

Each stage k starts from S^n with stage step c_k dt; its explicit part (1 - f_k) acts on the previous stage's state and its implicit part f_k on its own, so for dS/dt = lambda S and y = -lambda dt >= 0, S_k = (1 - (1 - f_k) c_k y S_{k-1}) / (1 + f_k c_k y), S_0 = 1. Each stage's state feeds the next stage's explicit terms, so every |S_k| must stay <= 1, not only the last. The result is decided analytically:

  • three stages (c = 1/3, 1/2, 1; compressible): bounded for f_1 >= 1/2, f_2 = 1 and any f_3 in [0,1]. |S_1| <= 1 iff f_1 >= 1/2: |1 - (1-f) x| <= 1 + (1-f) x <= 1 + f x for f >= 1/2, and for f < 1/2, S_1 -> -(1-f)/f < -1 as x -> infinity; S_2 = 1 / (1 + y/2); and S_3 = (1 + (f_3 - 1/2) y) / ((1 + y/2)(1 + f_3 y)), whose numerator is at most 1 + y/2 in size. The default 1 1 0 is Crank-Nicolson, 1 1 1 backward Euler.
  • two stages (c = 1/2, 1; anelastic MidPoint): bounded for f_1 = 1 and any f_2 in [0,1] (the same S_3 form); with f_1 < 1 and f_2 = 0, as MidPoint forces, the second stage grows without bound.

Every other pattern returns 1: some are not bounded (0 0 1, 1 0 0, and 0.995 0.1 0.0666, whose last stage reaches 1.0008 near y = 23.5), and the rest are not shown to be.

Explicit diffusion rates of one cell, for the diffusive time-step estimate dt * rate <= Fourier limit (1/2 for forward Euler in 3-D; the three-stage Runge-Kutta scheme's real-axis bound is about 2.5 / 4 = 0.63).

Momentum: the largest of the three component rows, u: mu_h (2 a + b) + e_uv mu_v / dz^2 + mu_v sqrt(a c) v: mu_h (a + 2 b) + e_uv mu_v / dz^2 + mu_v sqrt(b c) w: mu_v (a + b) + 2 e_w mu_v / dz^2 + mu_v (sqrt(a c) + sqrt(b c)), with c = 1/dz^2, plus 2 mu_p h^2 / dz^2 for the terrain-metric part. The horizontal diffusion of w uses mu_v: tau31 and tau32 carry the same edge-averaged mu_v as tau13 and tau23. The sqrt terms are the u-w and v-w cross derivatives (dw/dx in tau13, du/dz in tau31, ...), which stay explicit whether or not the implicit solve takes the second vertical derivative; they are always counted, since with dz > dx/m they exceed the vertical term (dx = 100 m, dz = 500 m: five times). (The expansion rate in tau11 also couples u to dw/dz, with mu_h; that is covered by "an estimate when mu_h != mu_v" below.) The metric term is an upper bound: the projected stresses of the terrain stress (ComputeStressVarVisc_T) carry mu_v today (ERF issue #4214) and would carry mu_h once that is changed, hence mu_p = max(mu_h, mu_v); with mu_v there, the K_h part of that coupling enters only through the mixed xi-zeta terms, so the bound can overstate that coupling by about alpha / 2 on steep slopes.

Scalar: K_h (a + b) + K_h h^2 / dz^2 + e K_v / dz^2; the K_h h^2 part (TerrainDiffusionGz) is explicit.

a = (m_x / dx)^2, b = (m_y / dy)^2 and h^2 = (m_x dx_drop / dx)^2 + (m_y dy_drop / dy)^2 is the squared physical slope; on a mesh without terrain pass h2 = 0. e is the explicit fraction of the vertical diffusion (ExplicitVerticalFraction): 0 when the implicit solve keeps every stage bounded, 1 otherwise. All diffusivities are dynamic (rho * nu); rates are in 1/s. The caller passes the largest diffusivities and the smallest density around the cell (NeighbourhoodMax, NeighbourhoodMinPositive), which bounds the row whatever face or edge averaging the operator uses.

  2. the slope limiter (only if use_slope): nu /= alpha^2 if |D_h| > max(10/Delta_h, 1e-3), nu /= alpha otherwise. |D_h| is the horizontal deformation sqrt((u_x - v_y)^2 + (u_y + v_x)^2), which equals ERF's sqrt(2 S_mn S_mn) of ComputeSmnSmn2D and WRF's sqrt(def2). Delta_h = sqrt(dx/m_x * dy/m_y), WRF's mlen_h.

noexcept

Slope factor alpha = max( sqrt(dx_drop^2 + dy_drop^2) / dz, 1 ) of a cell: the terrain drop across one cell measured in cell thicknesses, which is h * Delta_x / Delta_z with h the physical coordinate slope. This is the factor of WRF's Smagorinsky-2D slope limiter (dyn_em/module_diffusion_em.F, smag2d_km, diff_opt = 2). WRF averages |z_x| at the two x-faces and the two w-levels of the cell and multiplies by dx / msftx; here the drop is taken on the four x-edges of the cell (ERF heights are nodal) and carries no map factor, so that alpha is exactly h * Delta_x / Delta_z with the physical spacing. The two agree when the map factor is 1.
