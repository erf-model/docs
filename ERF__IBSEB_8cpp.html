Detailed Description

ERF-side hooks of the immersed-boundary surface energy balance.

The balance lives in IBFaceSet (one per level, ERF::m_ibseb); this file holds the three places ERF calls into it:

  • init_ibseb() from ERF::InitData_post(), after the immersed forcing has built the blanking on a fresh start or a restart;
  • ibseb_write_checkpoint() from ERF::WriteCheckpointFile(), per level;
  • ibseb_report() from ERF::post_timestep(). The inputs are parsed in ERF::ReadParameters() into ERF::ibseb_params. Every function is a no-op unless erf.ibseb.enable is set.
