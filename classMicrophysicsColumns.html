Detailed Description

Morrison, WSM6 and WDM6 sediment each column inside one per-column kernel over the k range of the box they are handed: the box top is treated as the top of the column (no inflow) and the box bottom as its ground (outflow booked as surface precipitation). That is only right when no column is split between boxes.

This class records, for one level's grids, whether any column is split between boxes stacked in z, and if so builds a "column layout": a BoxArray covering exactly the same cells in which every contiguous vertical run of covered cells lies inside one box. A scheme then copies its fields onto that layout, runs its unchanged column kernels, and copies the result back. The kernels only read and write their own column, so this gives the same arithmetic as a run whose grids were never split in z.

A run that does not reach the domain bottom (e.g. a refined patch aloft) has no ground, so the schemes accumulate surface precipitation only where klo is the domain bottom.
