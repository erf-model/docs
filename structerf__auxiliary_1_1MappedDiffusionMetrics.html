Detailed Description

Host metric views. Map factors are ERF's k=0 fields: u_x/u_y on x faces, v_x/v_y on y faces, m_x/m_y at cell centers. ax/ay and the device pointer to the stretched vertical spacing are read only for StretchedDz.
