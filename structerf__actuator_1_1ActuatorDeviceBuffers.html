Detailed Description

The buffers of the spreading kernels (spread_partial_norms, add_scaled_kernels) and of the sampler (sample_velocity_local), kept by their caller so that a step allocates no device memory once the buffers have reached their size. Passing none makes a call use its own.

◆ force_face_major

bool erf_actuator::ActuatorDeviceBuffers::force_face_major {false}

A switch for the unit tests only; a model leaves it false. When true, add_scaled_kernels() runs the face-by-face pass on the host too, which is the only pass a device has, so a CPU build can compare the two. Both give the same sources bit for bit; the face-by-face pass is the slower one on a host.
