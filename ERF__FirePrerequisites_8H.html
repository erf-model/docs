Detailed Description

Start-up checks of the atmosphere side of the fire coupling.

Verifies that ERF is configured so that a fire grid can be coupled to it, whichever fire engine runs on that grid:

  • MOST surface layer is active with proper boundary conditions
  • The level the fire grid refines exists and keeps its boxes
  • No z-direction MPI decomposition (all z-levels on same rank)
  • The level's boxes cover one rectangle
  • Grid divisibility by refinement factor

Each engine checks its own inputs after these (FireEngine::verify_prerequisites).

All checks use AMREX_ALWAYS_ASSERT_WITH_MESSAGE for actionable diagnostics.

Verify the ERF configuration the fire coupling needs.

Called once at startup from FireCoupler::initialize() after the SurfaceLayer is ready, before the engine's own checks. Aborts with clear diagnostic messages if any requirement is not met.

Checks performed (in order):

  1. SurfaceLayer pointer is not null (zlo.type = surface_layer), unless needs_surface_layer is false (FireEngine::needs_surface_layer)

  6. All boxes divisible by grid_ratio in x and y
