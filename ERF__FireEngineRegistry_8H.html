Detailed Description

The fire engines compiled into this executable.

ERF lists no engine itself. Each engine registers itself from its own .cpp with 

ERF_REGISTER_FIRE_ENGINE(MyEngine, "myengine")

at namespace scope, and erf.fire.engine then selects it by that name. The engine's directory (FIRE_HOME in GNU make, ERF_FIRE_ENGINE_DIRS in CMake) adds that .cpp to the build, so adding an engine changes no file of ERF.

The registration runs during static initialisation, so the .cpp that holds it must be linked as an object file: inside a static archive (.a) that nothing else references, the linker drops it and the engine is missing. ERF's CMake build compiles engines into its OBJECT library, and GNU make links every object, so both keep it; an engine that ships a prebuilt library keeps its registering .cpp as source (LSFIRE's wrapper does).
