Detailed Description

Conservative linear interpolation of a land-surface field that does not mix land and water (erf-model/ERF#4390), in the spirit of WRF's land/water-masked nest interpolation.

The coarse data carries two components: the field, and a land/water indicator (one value for water, another for land; NaN outside the domain). In each direction the slope of a coarse cell is taken only if both of its neighbours are of the same type as the cell; otherwise it is zero, as it is at a domain boundary. The min/max limiter likewise looks only at neighbours of the same type. Where every neighbour is of the same type this is exactly AMReX's cell_cons_interp (CellConservativeLinear without linear limiting), so the result changes only next to a coastline. Each coarse cell's mean is kept, and the indicator is copied (piecewise constant).
