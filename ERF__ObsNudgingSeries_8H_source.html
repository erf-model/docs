14 //
15 // The measurements of one observation-nudging station, as read from its file,
16 // and the profiles they give at a moment of the run.
17 //
18 // A station file is plain text. Everything from a '#' to the end of a line is
19 // a comment. The first line that is not blank names the columns, in any order:
20 //
21 // time z u v w theta su sv sw stheta
22 //
23 // time and z are required; the wind is given either as u v (east and north, or
24 // grid x and y, see wind_frame) or as speed direction (metres per second, and
25 // the meteorological direction the wind blows from, in degrees clockwise from
26 // north). w, theta and the standard deviations su sv sw stheta are optional,
27 // and a component with no column is not nudged at this station. Each row that
28 // follows is one height at one time. Rows are grouped by time in increasing
29 // order, and the heights within a time are in increasing order and the same at
30 // every time. An entry that is not a finite number ("nan"), or that equals the
31 // run's missing value, is missing: that component is not nudged at that height
32 // and time.
33 //

74 //
75 // The profiles of every component at time t.
76 //
77 // A file with one time holds for the whole run. A file with several is
78 // interpolated linearly in time between the two records that bracket t, and a
79 // height is used only where both records have the component; before its first
80 // time and after its last the station is inactive and every profile is empty.
81 //
82 // The wind is then rotated from the frame of the file into the grid frame:
83 // (cos_alpha, sin_alpha) is the direction of the grid x axis measured
84 // counterclockwise from the file's x axis (true east for an earth-relative
85 // wind). Unless the rotation is the identity it needs u and v together, so a
86 // height at which either is missing is dropped from both, and the standard
87 // deviations are rotated as those of independent components.
88 //
89 // Returns true when the station is active at t.
90 //
91 bool profiles_at_time (const StationSeries& series, double t,
92  amrex::Real cos_alpha, amrex::Real sin_alpha,
