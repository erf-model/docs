Detailed Description

Fill the SLM land surface model's initial state from a met_em file.

SLM's real-data initialization was written against the fields real.exe puts in a wrfinput file (TSLB, SMOIS, DZS, ZS, IVGTYP, ISLTYP, TSK, VEGFRA, SHDMIN, SHDMAX, LAI); see SLM::wrfinput_map and SLM::init_wrfinput_vars. A met_em file holds the raw ingredients real.exe builds those from, so here we do the same derivation and hand SLM the result in the same form, so that it takes exactly the path it takes for a wrfinput run.
