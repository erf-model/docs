Detailed Description

What a structure model reads once, at start-up.

All fields live on the level the model couples to (StructureModel::level()).

◆ fixed_dt

double StructureInit::fixed_dt

The nominal step of level lev [s]: erf.fixed_dt divided by the sub-cycling ratios down to lev. Not positive when the run has no fixed step (ERF then chooses each step from erf.cfl). StructureStep::dt is the step taken: it differs on the first steps with erf.init_shrink below 1 or after a restart (growth limited by erf.change_max), and on a last step that ERF fits to the stop time

◆ fully_compressible

bool StructureInit::fully_compressible

A level of the run, not only lev, is FullyCompressible (erf.compressibility_type); false when every level is Anelastic or PseudoIncompressible. It names the solver, not the time scheme: a FullyCompressible level with erf.timestepping_type = RK3_NoSubstepping counts

◆ stop_time

double StructureInit::stop_time

The time [s], on the clock of time, at which the run stops: the input stop_time, or stop_datetime less start_datetime; the largest double when neither is given. It is ERF's own stop, which can differ from the input by about 1e-7 s when start_datetime is given, so compare with a tolerance. max_step may end the run earlier
