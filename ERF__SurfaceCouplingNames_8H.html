Detailed Description

The names a surface coupling uses in its inputs and messages.

The fire and the flood couplings build on the same surface-coupling layer (Source/SurfaceCoupling): the 2D grid that refines one atmospheric level, the maps to and from its columns, the engine registry, the engine choice and the start-up checks. Each coupling hands the layer its names, so every input and message keeps the coupling's own words: erf.fire.grid_ratio, "[FIRE] ... the fire grid ...", erf.flood.anchor_level, and so on.
