Detailed Description

Checks of the height tables read from erf.terrain_file_name, erf.terrain_file_name_USGS and erf.buildings_file_name (ProblemBase::read_custom_terrain), a start-up summary of each table, and the warning for steep terrain next to an inflow or outflow face.

Table layouts:

  • ERF text format (nx, ny >= 1): x has nx values, y has ny values, and height n sits at (x[n / ny], y[n % ny]), i.e. y varies fastest. A single value in a direction makes the surface constant in that direction (a two-dimensional profile).
  • USGS format (nx, ny >= 2): x has one value per point, y one value per row of nx points, and height n sits at (x[n], y[n / nx]), i.e. x varies fastest.
