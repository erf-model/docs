MPI-collective completed-stage admission. All participating ranks must enter for the same host stage, including after a local recoverable error; callers must not branch around the call based on rank-local predicates. Asynchronous rank-local Abort or MPI process failure is outside this protection. A rejected in-progress transaction discards its partial accepted transfers everywhere. If every rank instead has a valid completed prior step and no rank has begun the next step, rejection leaves that prior completed transfer intact. Starting a valid new step invalidates the previous completed record. Read a transfer as accepted only while step_complete() is true; this object does not provide a retained snapshot.

MPI-collective stage admission. Every rank participating in this level's call must enter despite local recoverable errors; callers must not branch around it using rank-local predicates. Incomplete, invalid, mismatched, or nonfinite in-progress stages invalidate the partial record everywhere. If all ranks instead have a completed prior step and no active next step, a rejected idle call preserves that prior record. A valid new stage zero invalidates it. A rank that never enters, asynchronous Abort, or MPI process failure is outside this protection.
