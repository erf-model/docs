void verify_flood_prerequisites ( const ERF &  erf,
int  lev 
)

Verify the ERF configuration the flood coupling needs.

Checks, in order:

  1. 0 <= lev <= finest level
  2. On a level above 0: static refinement (erf.regrid_int <= 0)
  3. Every box of the level spans its full height (no z decomposition), so the level's k = 0 slabs are one box per atmospheric box
  4. The level's boxes cover one rectangle in x and y
  5. The domain starts at index 0 in x, y and z
