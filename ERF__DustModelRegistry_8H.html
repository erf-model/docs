Detailed Description

The dust models compiled into this executable.

ERF lists no model itself. Each model registers itself from its own .cpp with 

ERF_REGISTER_DUST_MODEL(MyModel, "mymodel")

at namespace scope, and erf.dust.model then selects it by that name. The model's directory (DUST_HOME in GNU make, ERF_DUST_MODEL_DIRS in CMake) adds that .cpp to the build, so adding a model changes no file of ERF.

The registration runs during static initialisation, so the .cpp that holds it must be linked as an object file (ERF's CMake build compiles model directories into its OBJECT library, and GNU make links every object). This is the scheme of the fire engines (ERF_FireEngineRegistry.H) and the structure models.
