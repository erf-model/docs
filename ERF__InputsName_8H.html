void CheckForDuplicateInputs ( const std::string &  inputs_file)
inline

Abort if a key is set twice in the inputs file, counting the files it includes with FILE = <name>. A file may re-set a key that a file it included earlier set (a base deck included first and then overridden); a key set twice in one file, in two files included side by side, or in a file and then again in a file it includes afterwards is refused. UNSET = <key> drops a key so it may be set again. Keys given on the command line are not checked; they override the file's.
