Detailed Description

Flood grid data structure, construction and the maps between the flood grid and the atmospheric columns.

A 2D grid on the horizontal plane, refined by grid_ratio relative to one atmospheric AMR level (erf.flood.anchor_level, the finest level by default). The flood grid covers that level's boxes, keeps their x-y decomposition and their MPI owners, and its index space starts at zero at the lower corner of the region they cover. The construction is the one of the fire grid (ERF_FireGrid.H), kept separate so that neither build needs the other.

Construct a refined 2D flood grid over one atmospheric level's boxes.

Parameters
[in]ba_atmBoxArray of the atmospheric level
[in]dm_atmDistributionMapping of the atmospheric level
[in]geom_atmGeometry of the atmospheric level
[in]CRefinement factor (erf.flood.grid_ratio, >= 1)
Returns
FloodGrid over the region the boxes cover; its lev is left at 0 for the caller to set.
  1. Take the k = 0 slab of each box in ba_atm, keeping the box order.
  2. The region is their bounding rectangle, which must be covered exactly (aborts otherwise); atm_lo is its lower corner.
  3. Shift the slabs by -atm_lo and refine by {C, C, 1}; box n keeps the owner of atmospheric box n, so dm_atm is reused.
  4. The Geometry spans the region: index space 0 to C * size - 1, the physical extent of the region (the domain's own bounds where the region spans the domain), periodic only in a direction the region spans.

Copy component acomp of a k = 0 atmospheric field into component fcomp of a flood-grid field: every flood cell takes the value of the atmospheric column it lies in, (i / C + atm_lo[0], j / C + atm_lo[1]). Box n of the flood grid refines box n of the atmospheric level and has the same owner, so one MFIter serves both MultiFabs. A per-area quantity (precipitation in kg/m2) keeps its column total: each of the C^2 cells under a column receives the column's value per unit area.
