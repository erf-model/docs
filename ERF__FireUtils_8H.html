Compute relative humidity from conserved atmospheric variables at k=0.

Computes RH from pressure, temperature, and water vapor mixing ratio at the first atmospheric level (k=0). Uses the ERF microphysics saturation vapor pressure functions.

Parameters
[out]RH_outOutput relative humidity MultiFab [fraction 0-1] Must be allocated with ncomp=1 on same grid as inputs
[in]S_atmConservative state at k=0 Contains RhoTheta (comp 1) and RhoQ1 (comp 4)
[in]geomGeometry at level 0
Note
  • Output is clamped to [0, 1] range
  • Assumes S_atm contains standard conserved variables (Rho, RhoTheta, RhoQ1)
  • Temperature extracted from RhoTheta using standard EOS
  • Pressure computed from RhoTheta and qv using getPgivenRTh

Air temperature [K] at k = 0 from the conserved state.

T = theta * (p / p_0)^(R_d / c_p), with p from RhoTheta and qv as in compute_rh_from_conservative. Fuel-moisture curves and ignition criteria take an air temperature, not the potential temperature of the first cell, which at 840 hPa is 14-16 K above it.

Copy a MultiFab between device and host-accessible memory, for an engine whose fire physics runs on the host.

The memory contract of ERF_FireEngine.H: the coupling's fields are in the default arena (device memory on a GPU build) and are only valid during the call that hands them over; an engine's returned fields must be readable there too. dst and src have the same BoxArray and DistributionMapping; ncomp components and nghost ghost cells are copied from component 0. dst belongs to the caller (allocate a host copy once with amrex::MFInfo().SetArena(amrex::The_Pinned_Arena()), or The_Managed_Arena(), and reuse it). The copy completes before the call returns: the GPU stream is synchronised, so the host may read dst, or the device read it, right away. On a CPU build it is a plain copy.
