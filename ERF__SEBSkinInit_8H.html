Detailed Description

The first value of the two-stream force-restore balance's skin temperature from the skin temperature of the initial file (TSK of a wrfinput file, SKINTEMP of a metgrid file), with erf.radiation.seb_init_skin_from_file.

Without the input every column starts at the one value erf.rad_t_sfc. With it a land column starts at the file's value. A water column keeps erf.rad_t_sfc: the balance does not run there and the sweep takes the surface layer's sea surface temperature.
