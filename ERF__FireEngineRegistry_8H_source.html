18  * ERF lists no engine itself. Each engine registers itself from its own .cpp
19  * with
20  *
21  * ERF_REGISTER_FIRE_ENGINE(MyEngine, "myengine")
22  *
23  * at namespace scope, and erf.fire.engine then selects it by that name. The
24  * engine's directory (FIRE_HOME in GNU make, ERF_FIRE_ENGINE_DIRS in CMake)
25  * adds that .cpp to the build, so adding an engine changes no file of ERF.
26  *
27  * The registration runs during static initialisation, so the .cpp that holds
28  * it must be linked as an object file: inside a static archive (.a) that
29  * nothing else references, the linker drops it and the engine is missing.
30  * ERF's CMake build compiles engines into its OBJECT library, and GNU make
31  * links every object, so both keep it; an engine that ships a prebuilt
32  * library keeps its registering .cpp as source (LSFIRE's wrapper does).
