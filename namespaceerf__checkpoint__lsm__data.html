Detailed Description

File names of the LSM data in a checkpoint.

lsm_data[i] is written as "LsmData<i>". The Noah-MP snow and snowh fields were added in the middle of that numbering, which would shift every later index (the soil fields) by two and make an older checkpoint restart with the wrong fields. They are therefore stored under their own names and left out of the numbering, so every other field keeps the index it always had. A restart from a checkpoint that predates them keeps their initial values.
