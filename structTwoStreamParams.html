Detailed Description

Trivially copyable subset of RadChoice used by the column kernels.

RadChoice carries std::string members (diagnostics file name, call-site mode) and therefore cannot be captured by value in a GPU device lambda. The level driver builds one TwoStreamParams per call with make_two_stream_params() and passes that to vertical_two_stream_sweep() and its helpers. Field names match RadChoice.
