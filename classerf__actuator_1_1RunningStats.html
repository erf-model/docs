Detailed Description

One set of running statistics: the mean, the root mean square, the minimum and the maximum of each named scalar quantity over every sample added since the caller's averaging start. write() rewrites <output_root>_stats.csv with the current values; the sums are part of the checkpoint, so the statistics continue across a restart. A non-finite sample aborts, naming the statistics and the quantity.
