Detailed Description

Ghost-cell fill for planar (2D) MultiFabs built on the collapse of a 3D BoxArray along a surface-normal direction.

The surface-layer fields and the MOST averages are defined on one 2D box per 3D box. When the 3D BoxArray is split in the normal direction, several 3D boxes collapse onto the same 2D box, so the planar BoxArray holds duplicate boxes with overlapping valid regions, and only the copy that belongs to the 3D box touching the surface is ever computed. A FillBoundary on such a MultiFab may fill a ghost cell from an uncomputed copy.

define() records which planar boxes are those surface copies. fill() copies them into a buffer without duplicates and ParallelCopies the buffer onto every planar box, valid region and ghost cells alike. Unlike FillBoundary it therefore also overwrites the valid region of the uncomputed copies, so that any copy can be read afterwards. Without duplicates fill() is a plain FillBoundary.

The buffer is kept for each target layout, index type, and number of components, so only the first fill of each kind allocates. For a face-centered MultiFab (the MOST velocity averages) neighboring surface boxes share a face in the buffer. Both should hold the same value there, but nothing enforces it, so fill() gives the shared faces a single value before it copies: the lowest global box index wins, which does not depend on the decomposition or the rank count, and every copy of the field then agrees.

A level none of whose boxes reaches the surface (a fine level away from the surface) has no computed copy to fill from, and fill() leaves the MultiFab as it is.

The strips beyond the non-periodic domain edges owned by each surface copy of a planar layout, built on first use.

A surface copy that touches a non-periodic edge owns the ghost cells beyond it that face its valid region, out to the ghost width of the field, and at a domain corner the cells beyond both edges. Since the surface copies do not overlap, neither do these strips.

The remaining cells beyond a non-periodic edge that lie in the ghost region of a surface copy face a column no grid of the level covers. Each goes to the surface copy with the lowest global index that holds it, in the image inside the domain in the periodic directions, so that the ParallelCopy from the strips reaches all its images.

void PlanarBoundary::reconcile_outside_domain ( amrex::MultiFab &  mf,
const amrex::Geometry &  geom 
)

Give every copy of a ghost cell outside a non-periodic lateral domain edge the value of the surface copy that holds the column it faces.

Where a box seam meets a non-periodic edge, the ghost cells beyond the edge next to the seam lie in the grown boxes of both neighbors, and no FillBoundary reconciles them: each box fills its copy from its own valid region. A cell beyond the edge is here assigned to the surface copy whose valid region holds the cell's projection into the domain (its index clamped into the domain in each non-periodic direction), and that copy's value is written into every other copy, periodic images included. The result then does not depend on the decomposition, and a checkpoint, which keeps one copy, restarts from the same values. Only ghost cells beyond a non-periodic edge are written; interior, periodic and coarse/fine ghost cells are left as they are.

On a fine level the column a cell beyond the edge faces need not be covered by any grid: where a coarse/fine boundary meets the domain edge, or two grids along the edge are separated by a gap narrower than twice the ghost width. Such a cell has no owner by projection, and it takes instead the value of the surface copy with the lowest global box index whose ghost region holds it (OverrideSync's precedence in fill()), so it too has one value that does not depend on the decomposition. Only surface copies take part: a cell held solely by the ghost region of an uncomputed copy (a 3D box above the surface whose footprint differs from those below it) is left as it is.

Call it after fill(), on a cell-centered planar MultiFab; other index types are left as they are.
