6 /**
7  * @file ERF_FireEngineTemplate.H
8  * @brief A starting point for a new fire engine: declarations only
9  *
10  * This class declares every FireEngine method a new fire model provides and
11  * says what ERF hands it and expects back. Nothing here has a body, no input
12  * selects it and nothing creates one, so it adds no code to ERF. The stand-in
13  * engine of the FireCoupler unit tests (Tests/Unit/Fire/ERF_GTestFireCoupler.cpp)
14  * is the smallest engine that works.
15  *
16  * To start a new engine:
17  * 1. Copy this file into the new model's engine directory (outside ERF),
18  * rename the class and the include guard, and write the bodies in a .cpp
19  * file there. Delete the
20  * declarations of the optional methods the engine does not provide (their
21  * defaults in FireEngine then apply); a declaration left without a body
22  * fails to link.
23  * 2. Read the model's inputs under its own prefix (fire.<engine>.* is
24  * recommended), so they never mix with the coupling's keys
25  * (FireCouplingParams, erf.fire.*) or another engine's.
26  * 3. Register the engine in that .cpp, at namespace scope:
27  * ERF_REGISTER_FIRE_ENGINE(MyEngine, "my_fire")
28  * (ERF_FireEngineRegistry.H), and give the engine directory a
29  * Make.package (GNU make, FIRE_HOME) and an ERFFireEngine.cmake defining
30  * erf_fire_engine_add(target) (CMake, ERF_FIRE_ENGINE_DIRS).
31  * Tests/FireEngineExample is a complete engine directory to copy.
32  * 4. Run the FireCoupler unit tests with the new engine in place of their
33  * stand-in, and a restart of a coupled run against a straight run: the
34  * atmosphere and fire plotfiles must agree at zero tolerance.
35  *
36  * What the coupling layer already does for every engine: it builds the fire
37  * grid over erf.fire.anchor_level, hands the engine the atmosphere's state
38  * each step, averages the engine's fluxes onto the atmospheric columns, holds
39  * them one step, injects heat, vapour and smoke, and saves those lagged fluxes
40  * in the checkpoint. An engine owns only its fire physics and its own state.
41  *
42  * The call order is the one documented on FireEngine (ERF_FireEngine.H).
43  * ERF_FireCoupler.cpp checks at compile time that this class declares every
44  * method FireEngine requires (the pure virtual ones), and override checks the
45  * signature of every method declared here. The optional methods are listed by
46  * hand: a new optional method in FireEngine is added here too.
47  */
