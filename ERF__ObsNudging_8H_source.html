25 //
26 // Nudging towards observations at stations (met masts, lidars, profilers).
27 //
28 // Each station is a horizontal position and a time series of measured
29 // profiles (see ERF_ObsNudgingSeries.H for the file). Near a station the
30 // velocity components and the potential temperature relax towards the
31 // measurements, with a weight that falls off with the distance from the
32 // station horizontally and from its measured height range vertically, and
33 // only the part of the local value outside the measured variability, mean +-
34 // alpha sigma, is relaxed (see ERF_ObsNudgingKernel.H for the formula).
35 //
36 // Heights are measured above the local terrain (or, per station, above the
37 // model's z = 0): on a terrain-fitted mesh the terrain is the bottom of the
38 // mesh, with immersed-forcing terrain it is the terrain surface the immersed
39 // boundary is built from, and cells inside the immersed terrain or buildings
40 // are not nudged. A station can be placed by x/y in domain coordinates or, in
41 // a run with latitude/longitude arrays, by lat/long; an earth-relative wind is
42 // rotated into the grid frame with the orientation of the grid at the station.
43 //
44 // Inputs are under erf.obs_nudging; see the Inputs section of the docs.
45 //
46 struct ObsNudgingStation
47 {
48  std::string name;
49  std::string file;

51  bool use_latlon = false;
52  amrex::Real req_lat = amrex::Real(0.0);
53  amrex::Real req_lon = amrex::Real(0.0);
54 
55  // Domain coordinates, given or resolved from lat/long
56  amrex::Real x = amrex::Real(0.0);
57  amrex::Real y = amrex::Real(0.0);
58 
59  // The lat/lon actually reached, for a station placed by lat/long
60  amrex::Real got_lat = amrex::Real(0.0);
61  amrex::Real got_lon = amrex::Real(0.0);
62 
63  bool earth_frame = true; // the wind in the file is east/north
64  bool agl = true; // heights are above the local terrain
65 
66  // Rotation from the frame of the file to the grid frame
67  amrex::Real cos_alpha = amrex::Real(1.0);
68  amrex::Real sin_alpha = amrex::Real(0.0);
69 
70  obs_nudging::StationSeries series;
