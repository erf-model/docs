Detailed Description

Start-up checks of the atmosphere side of the flood coupling.

Verifies that ERF is configured so that a flood grid can be coupled to it, whichever flood engine runs on that grid. Each engine checks its own inputs after these (FloodEngine::verify_prerequisites). Every check aborts with a message that names the input to change.

Verify the ERF configuration the flood coupling needs.

Checks, in order:

  1. 0 <= lev <= finest level
  2. On a level above 0: static refinement (erf.regrid_int <= 0)
  3. Every box of the level spans its full height (no z decomposition), so the level's k = 0 slabs are one box per atmospheric box
  4. The level's boxes cover one rectangle in x and y
  5. The domain starts at index 0 in x, y and z
