using ScalarDiffusionRefluxViews = amrex::GpuArray<const amrex::Array4<amrex::Real>, AMREX_SPACEDIM>

Face views into which the diffusive fluxes of each component are accumulated for refluxing, indexed by state component, in the convention of the advective fluxes the flux registers hold: a state update of -(m_x m_y / detJ) div F. Null when nothing is refluxed.
