Detailed Description

The real-boundary maps of the conserved state, one entry per conserved component up to NVAR_max: whether the component is read from the WRF/metgrid boundary data (read), from which boundary field (map), and from which boundary-plane slot when planes are read as well (bnd, cons_bc_comp). Density is read with erf.use_wrf_bdy_density, theta and the water vapour always; passive scalars never. Hydrometeor mappings retain the upstream read flags, which do not enable hydrometeor ghost-cell fills. Built from the component layout, so every passive scalar (NSCALARS of them) sits between RhoKE_comp and RhoQ1_comp.
