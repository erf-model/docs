Detailed Description

Conservative linear interpolation that does not mix cells of different types, in the spirit of WRF's land/water-masked nest interpolation (erf-model/ERF#4390). Every cell is interpolated; a cell's type decides only which neighbours its slopes and limiter may see. The types are whatever the caller encodes: land and water (SLM's state), a valid value and the lsm_undefined sentinel (Noah-MP), or both at once (SLM's fluxes).

The coarse data carries nfield fields followed by nind type indicators (one value per type; NaN, no type, outside the domain). With nind == 1 every field shares the one indicator; with nind == nfield field n has indicator n. In each direction the slope of a coarse cell is taken only if both of its neighbours are of the same type as the cell; otherwise it is zero, as it is at a domain boundary. The min/max limiter likewise looks only at neighbours of the same type. Where every neighbour is of the same type this is exactly AMReX's cell_cons_interp (CellConservativeLinear without linear limiting), so the result changes only next to a type boundary. Each coarse cell's mean is kept, and the indicator is copied (piecewise constant), so a cell whose neighbours are all of other types (an isolated sentinel, say) comes through exactly.
